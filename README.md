# Solutions Manual: Introduction to Quantum Mechanics
**David J. Griffiths, 2nd Edition**

Worked solutions to exercises from Griffiths' *Introduction to Quantum Mechanics*, typeset in LaTeX.

## Building

Compile with `pdflatex` or `latexmk`:

```bash
cd introquantummechanics && latexmk -pdf introquantummechanics.tex
```
